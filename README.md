# Здоровяк — личное приложение здоровья (v0.4.0)

Android, Kotlin + Jetpack Compose, Room. Своего сервера нет: все данные на телефоне, наружу уходят только запросы к Claude API, Open Food Facts, Garmin и (если включить) облачному синтезу речи.

## Установка на телефон (POCO X5)

1. Скопировать `Zdorovyak-0.4.0-debug.apk` на телефон (Telegram «Избранное», USB, Google Drive).
2. Открыть файл, разрешить установку из этого источника (MIUI спросит сам).
3. В приложении: ⚙ Настройки → вставить ключ Claude API → «Проверить ключ». Там же пол, возраст, рост, активность, цель и темп (нормы КБЖУ считаются сами) и вход в Garmin. Нормам нужно хотя бы одно взвешивание на вкладке «Тело».

Обновление: ставится поверх, данные сохраняются (пока подпись та же — см. «Подпись» ниже).

## Что умеет

| Раздел | Что есть |
|---|---|
| Сегодня | Кольца КБЖУ (калории + белок/жиры/углеводы против нормы, перебор — вторым кругом); неделя силовых из календаря и что сегодня по плану; сон, Body Battery, HRV, стресс (Garmin); вес и тренд |
| Питание | Кольца КБЖУ, доля приёмов пищи, столбики калорий за 7 дней против нормы. Ввод фразой или голосом («гречка 200, две котлеты, чай с сахаром»): Claude делит на продукты и граммы, КБЖУ берётся из базы, чего нет — оценка ИИ с пометкой; фото тарелки по той же схеме. Порции (шт., ложка, стакан, тарелка — `nutrition/Portions.kt`). Нормы КБЖУ считаются сами: Миффлин–Сан Жеор от тренда веса, затем раз в неделю адаптивный расход по факту (съеденное + тренд веса, как в MacroFactor). Ввод «гречка 180» → поиск по своему справочнику и встроенной базе ≈400 продуктов и блюд (русская и казахская кухня), КБЖУ считается само; фото этикетки → Claude читает пищевую ценность на 100 г; оценка ИИ по названию с пометкой; штрихкод (Open Food Facts, без КБЖУ — предлагает этикетку); фото тарелки; «как вчера» для приёма пищи; у продуктов в справочнике виден источник цифр |
| Тело | Вес (+% жира), ИМТ, среднее по 7 записям, график; замеры талии/груди/бёдер/руки/бедра/шеи; карточка «Анализы» |
| Анализы | PDF из лаборатории или фото бланка → Claude переносит все показатели в таблицу (канонические коды ≈85 показателей, чтобы сводить разные лаборатории; однозначные пересчёты единиц) → динамика по датам с подсветкой вне референса, график по показателю, правка значений и даты. «Разобрать» — ИИ-интерпретация с учётом прошлых анализов, веса, питания, тренировок и сна, с пометкой «не диагноз, обсудить с врачом». Файл хранится в приложении, его можно открыть. Коуч видит анализы за 18 месяцев |
| Тренировки | Календарь: дни недели выбираете сами (Пн-Ср-Пт и т.п.), программа A→B→C идёт по плановым дням; отметки «сделал без записи / пропуск / болею / поездка / перенести на завтра»; серия недель без пропусков и % выполнения за 4 недели (болезнь и поездки не портят); сетка 5 недель; напоминание в день тренировки в выбранный час. Настройка инвентаря и красных флагов → Claude собирает программу из каталога (≈60 упражнений) → движок проверяет и при ошибках просит исправить (до 3 раз), без ключа — базовый план. Прикидка 2 тренировки, дальше прогрессия по «легко / нормально / тяжело» + фактические повторы + боль. Прочая активность (RPE × активные минуты, зоны) разгружает следующую силовую. Кардио из Garmin |
| Коуч | Чат с Claude: КПТ/коучинг, видит данные приложения за неделю и анализы, долговременная память (обновляется каждые 10 сообщений, видна и редактируется), границы и номера помощи (150, 112). Голос: микрофон (распознавание русской речи Google на телефоне, бесплатно), озвучка ответов на выбор — Google TTS на телефоне (бесплатно), Yandex SpeechKit или Google Cloud TTS (ключ в настройках); озвучивать «если спросил голосом» / всегда / по кнопке |

Правила прогрессии — `strength/Engine.kt`, по спеке `research/strength-module-spec.md`: «тяжело» держит, два раза подряд — минус 5–10%; «нормально» +1 повтор, на верху диапазона — шаг веса не больше +5%; «легко» +5% крупные / +2,5% мелкие; крупный шаг гантелей → растут повторы, потом подходы (до 4); боль 3–4 → −10%, ≥5 → замена упражнения; больше половины «тяжело» → без повышений; разгрузка каждую 5-ю неделю; перерыв 2–4 недели → −10%, больше 4 → новая прикидка. «Тяжело» после тяжёлой физработы на те же мышцы не штрафуется.

Нормы питания — `nutrition/Targets.kt`, по плану `docs/research/nutrition-improvements-plan.md`: расход = BMR × активность, пока за 3 недели не наберётся 10 полных дней питания (≥60 % нормы) и 4 взвешивания; дальше раз в неделю расход по факту = средние ккал − Δтренда веса × 7700 / дней, сдвиг осторожный (первый раз до ±300, потом до ±150 ккал). Норма = расход − темп × 7700 / 7, дефицит не больше 25 % расхода и не ниже BMR. Белок 1,8 г/кг (при ИМТ > 30 — от целевого веса), жиры ≥ 0,8 г/кг, углеводы — остаток. Активные ккал Garmin в бюджет не добавляются. Встроенная база — `assets/foods_ru.tsv` (таблицы Скурихина/ФИЦ питания и USDA, проверка по Этуотеру в тесте).

## Garmin

Официального API для личного использования у Garmin нет, поэтому вход повторяет python-библиотеку `garminconnect` 0.3.x (старый способ через `garth`/OAuth1 Garmin сломал в 2025 году): вход как iOS-приложение Garmin Connect (`sso.garmin.com/mobile/api/login`), при блокировке — запасной HTML-виджет SSO, затем обмен тикета на DI OAuth2-токены (`diauth.garmin.com`), дальше токен обновляется сам, пароль не нужен. Поддержан код двухфакторки. Синхронизация вручную и в фоне раз в 6 часов: шаги, пульс покоя, сон и его оценка, HRV, Body Battery, стресс, активные ккал, последние 20 активностей.

**Не проверено на живом аккаунте**: из среды сборки Garmin недоступен. Первый вход покажет, работает ли. Если Garmin поменяет вход, сломается только синхронизация, остальное приложение работает.

## Сборка

```
echo "sdk.dir=/путь/к/Android/Sdk" > local.properties
./gradlew :app:assembleDebug          # APK: app/build/outputs/apk/debug/
./gradlew :app:testDebugUnitTest      # юнит-тесты движков, норм, базы продуктов, миграции Room + сквозной Robolectric-прогон UI
```

JDK 17+, Android SDK 35. Открывается в Android Studio как обычный проект.

## Подпись

APK подписывается своим ключом, чтобы новые сборки с любой машины ставились поверх старых без потери данных. Ключ в git не хранится: файлы `keystore/zdorovyak.jks` и `keystore/keystore.properties` лежат в папке проекта Claude (`/mnt/project-files/health-app/keystore/`), их нужно положить в `keystore/` перед сборкой. Без них сборка подпишется отладочным ключом машины и поверх установленной версии не встанет.

## Структура

```
app/src/main/java/com/tikhomirov/zdorovyak/
  data/       Room (сущности, DAO), Settings (профиль; ключи в EncryptedSharedPreferences)
  ai/         ClaudeClient — Messages API на OkHttp, текст + изображения + PDF; Images — сжатие фото
  nutrition/  NutritionRepo — Open Food Facts, анализ фото
  strength/   Catalog, Engine (прогрессия, прикидка, валидатор, запасной план), TrainingRepo
  coach/      CoachRepo — системный промпт, сводка данных, долговременная память
  labs/       LabParser (разбор ответа, канонические коды, флаги, таблица динамики), LabsRepo (импорт PDF/фото, ИИ-разбор)
  voice/      VoiceInput (SpeechRecognizer, ru-RU), Speaker (TextToSpeech / облако), CloudTts (Yandex v1, Google v1), TtsText
  garmin/     GarminClient (SSO + OAuth1/2), GarminSyncWorker
  ui/         экраны Compose
```

## Голос коуча: сколько стоит

Оценка: 10 ответов в день × ≈800 символов ≈ 240 тыс. символов в месяц.

| Вариант | Качество русского | В месяц |
|---|---|---|
| Google TTS на телефоне (сетевой голос) | приличное, слышно синтез | 0 ₸ |
| Google Cloud TTS (WaveNet / Chirp 3 HD) | хорошее | 0 ₸ в пределах 1 млн бесплатных символов |
| Yandex SpeechKit API v1 | лучшее для русского | ≈1 600 ₸ (6 710 ₸ / 1 млн символов с НДС) |

Распознавание речи — системное Google, бесплатно. Цены на 20.11.2026: aistudio.yandex.ru/ru/docs/speechkit/pricing; Google — cloud.google.com/text-to-speech/pricing.
