# Граф знаний проекта (graphify)

Карта кода и документов приложения «Здоровяк»: классы, функции, экраны, таблицы Room
и концепции из спек (`docs/research/*.md`, `README.md`), со связями между ними.

| Файл | Что это |
|---|---|
| `GRAPH_REPORT.md` | Краткий отчёт: сообщества (модули), главные узлы, неожиданные связи. Читать первым. |
| `graph.json` | Сам граф. Запросы через `graphify query / path / explain`. |
| `graph.html` | Интерактивная визуализация, открывается в браузере без сервера. |
| `manifest.json`, `.graphify_labels.json` | Служебные: что уже извлечено и названия сообществ. |

## Как читать (до того, как лезть в код)

```bash
graphify query "как считается прогрессия веса в силовых?"
graphify explain "Engine"
graphify path "CoachRepo" "AppDatabase"
graphify section "Прогрессия"        # текст раздела из .md без открытия файла
```

## Как обновить после релиза — одна команда

Из корня репозитория:

```bash
pip install -q graphifyy && graphify update . && git add graphify-out && git commit -m "graph: update"
```

`graphify update .` перечитывает только изменённые файлы кода (AST, без LLM и без затрат),
сохраняет узлы из документов и названия сообществ.

Если менялись **документы** (`docs/**/*.md`, `README.md`) или добавлены новые спеки,
нужна семантическая переэкстракция: в сессии Claude Code скажи `/graphify . --update`.
Если файлы удалялись и граф «усох» — `graphify update . --force`.
Если после большого рефакторинга названия сообществ поплыли — `/graphify . --cluster-only`.
